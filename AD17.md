# Altium Designer 17

The AD17 plugin targets **x86 / .NET Framework 4.8**, using AD17's SDK and DevExpress 15.2. It uses the older pad/text interfaces and WPF theme fallback; HTTP uses TLS 1.2 and gzip/deflate.

It also includes a [Manufacturer Part Search prototype](ManufacturerPartSearch.md) using Altium's native supplier interfaces and library picker.

**Status:** installed and tested in AD17.1 under Wine with .NET Framework 4.8. EasyEDA search, previews, and RP2040 symbol, footprint, and embedded STEP imports work. Native Manufacturer Part Search returns Ciiva parts, parameters, stock, and price breaks; exact MPN filtering and copying a matching library component work. Schematic placement, saving, undo, and redo pass for both import paths. Earlier runs hit model-server warnings, and large-board STEP loading still stalls.

Build and package on macOS:

```sh
ALTIUM_VERSION=17 ./tools/build-macos.sh
pwsh -NoProfile -File Package.ps1 -AltiumVersion 17
```

`ALTIUM_INSTALL_DIR` can point to a different AD17 installation. On Windows:

```powershell
.\Build.ps1 -AltiumVersion 17 -AltiumInstallDir 'C:\Program Files (x86)\Altium\AD17'
.\Package.ps1 -AltiumVersion 17
```

Output is isolated in `EasyEDA-Loader/bin/ad17/Release`, `dist-ad17`, and `release/EasyEDALoader-ad17.zip`. Altium and DevExpress DLLs are not bundled. The standalone viewer remains AD26 only.

Install using `python3 tools/deploy-wine.py --altium-version 17` on macOS, or `Deploy.ps1 -AltiumVersion 17 -ExtensionsRoot '<AD17 extensions directory>'` on Windows. The extracted archive includes `dist-ad17` and the Windows installer scripts.

Set `EASYEDA_LIBRARY_DIR` to a disposable folder for testing. Runtime errors are logged to `%LOCALAPPDATA%\EasyEDALoader\runtime-errors.log`; primitive import errors are logged beside the output libraries.
